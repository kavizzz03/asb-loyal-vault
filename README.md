# ASB Group - Loyalty Vault System

An enterprise customer loyalty platform for **ASB Group**. This system enables real-time customer onboarding via secure OTP verification, dynamic loyalty point calculation, and real-time vault balance tracking.

## ✨ Core Features

* **📱 Secure OTP Authentication:** Real-time SMS/WhatsApp OTP registration and login workflow for seamless customer onboarding.
* **⚡ Real-Time Loyalty Vault:** Instant tracking and updating of customer loyalty points, rewards, and redemption balances.
* **💰 Automated Point Calculations:** Dynamic engine to credit points based on purchase activity and promo events.
* **🛡️ Enterprise Infrastructure:** Built for high-throughput transactional logic, audit logs, and secure database updates.
